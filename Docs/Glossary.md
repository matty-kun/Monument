# Domain Glossary

*   **Tournament (or Season/Games)**: A distinct, time-bound intramural event (e.g., CITE FEST 2026, SIDLAK 2026). Acts as the primary partition for all data.
*   **Department**: The base organizational unit (e.g., IT, Engineering).
*   **Participating Team**: The historical snapshot of a Department's identity (name, abbreviation, mascot) specifically for a single Tournament.
*   **Tournament Event**: The historical snapshot of a sport or competition (including its name, category, rules) bound to a specific Tournament.
